# **App Name**: Cinta Abadi

## Core Features:

- Welcome & Event Overview: Displays key wedding details such as date, time, and location, designed for easy mobile viewing.
- Love Story Timeline: Presents the couple's journey and memorable moments in an engaging, scrollable format.
- Guest RSVP Interface: Allows guests to easily confirm their attendance through a streamlined form.
- Digital Photo & Video Album: A curated gallery to showcase wedding photos and videos, optimized for mobile display.
- Interactive Pill Navigation: Mobile-optimized pill-shaped navigation with thematic icons for smooth transitions between different sections as users scroll.
- Animated UI Elements: Smooth transitions and elegant micro-interactions applied to all elements using Framer Motion to enhance user experience.

## Style Guidelines:

- Primary color: A sophisticated muted grey (#A8A8A8), representing modern elegance, used for secondary elements and containers.
- Text color: Pure white (#FFFFFF) for maximum contrast and readability against dimmed and blurred background images.
- Accent color: Pure white (#FFFFFF) for key interactive elements such as buttons, navigation pills, and essential highlights, ensuring high visibility.
- Secondary accent: A dark grey (#555555) can be used for subtle highlights or decorative elements to complement the primary palette.
- Background images will be overlaid with a semi-transparent dark dimming filter to enhance text readability.
- Headline font: 'Playfair Display' (serif) for an elegant and fashionable aesthetic; Body text font: 'PT Sans' (humanist sans-serif) for warmth and readability.
- Utilize minimalist, elegant line-art or glyph-based icons for the pill navigation and other UI elements to maintain a clean aesthetic.
- Mobile-first design with vertically scrolling sections. Components will leverage Radix UI for accessibility and robust interaction.
- Each distinct section or 'page' will feature a unique, full-bleed background photograph of the couple.
- Background images will incorporate a subtle blur effect to enhance aesthetic appeal while maintaining text legibility.
- Content areas will be strategically positioned in the lower half of the screen to preserve visibility of background imagery, especially the couple's faces.
- Every interactive element and content section will feature subtle, smooth animations and transitions powered by Framer Motion, enhancing user engagement and flow.
