  → Run SQL migration in Supabase SQL Editor

  → Check Supabase project CORS settings

  → Check Realtime is enabled in Supabase settings

  → Verify exact SQL policies from 01_create_schema.sql

================================================================================
  KEY DIFFERENCES FROM FIREBASE
================================================================================

Database:        Firestore (NoSQL) → PostgreSQL (SQL)
Real-time:       Listeners → Subscriptions
Queries:         Firestore API → SQL + Hooks
Security:        Security Rules → Row Level Security (RLS)
Hosting:         Firebase → Supabase
Cost Model:      Per operation → Database size
