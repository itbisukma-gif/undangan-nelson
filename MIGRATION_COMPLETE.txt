================================================================================
                        DATABASE SCHEMA
================================================================================

Table: public.wishes

  Column        Type                      Notes
  ─────────────────────────────────────────────────────
  id            UUID PRIMARY KEY          Auto-generated
  name          TEXT NOT NULL             Guest name
  status        TEXT NOT NULL             'Hadir' or 'Absen'
  message       TEXT NOT NULL             Guest message
  created_at    TIMESTAMP WITH TIME ZONE  Auto-generated

Security:
  ✓ RLS Enabled
  ✓ Allow public read (anyone can read)
  ✓ Allow public insert (anyone can submit)
  ✓ Prevent update/delete (immutable records)

Indexes:
  ✓ idx_wishes_created_at (for ordering)
  ✓ idx_wishes_status (for filtering)
